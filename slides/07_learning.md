# As a senior scientific software author
- AI amplifies strengths, so be the architect
- decide what to build
- decide how to build it
- decide level of quality and reusability
- review
<br/><br/>
Critical thinking is your superpower

---

# As a medior scientific software author
- concentrate on code review
- concentrate on code quality
- concentrate on modules, boundaries, reuse
- use AI to learn more about new topics
<br/><br/>
Critical thinking is your superpower

---

# As a junior scientific software author
- use AI to learn, to help you struggle
- ask the AI ‘why’
- only use AI generated code if you can explain it to someone else
- practice without AI
- focus on testing, verification and scientific reproducibility
<br/><br/>
Critical thinking is your superpower
